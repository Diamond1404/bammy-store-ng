# 🛍️ BAMMY STORE NG
### Your Everyday Shopping Destination

BAMMY STORE NG is a modern, responsive Nigerian online shopping platform created to make shopping for everyday essentials, fashion accessories and lifestyle products simple, convenient and affordable.

Our goal is to provide customers with a smooth online shopping experience, offering quality products across different categories with convenient checkout and payment options.

---

## 🌟 About the Project

BAMMY STORE NG is an e-commerce website designed with a clean, attractive and user-friendly interface. The platform features a professional product catalogue, shopping cart, checkout system and payment integration architecture.

The website uses a modern combination of **Emerald Green, Grey and Orange** to create a distinctive and memorable shopping experience.

## 🛒 Product Categories

Our online store is organized into six major shopping categories:

| Category | Description |
|---|---|
| 🍳 Kitchen & Home | Kitchen utensils and household essentials. |

## 🚀 Getting Started

Follow these instructions to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Diamond1404/bammy-store-ng.git
```

### 2. Enter the Project Folder

```bash
cd bammy-store-ng
```

### 3. Install Backend Dependencies

```bash
cd server
npm install
```

### 4. Configure Environment Variables

Create your `.env` file using the provided `.env.example` file.

Add your required configuration, including your Paystack secret key.

**Important:** Never upload your `.env` file or secret API keys to GitHub.

### 5. Start the Backend Server

Use the start command configured in your `server/package.json`.

### 6. Open the Website

Open the frontend `public/index.html` in a browser or serve the public folder through your configured web server.

## 💳 Payment Integration

BAMMY STORE NG includes a payment integration structure designed around Paystack to support Nigerian online payments.

The intended payment options include:

- Debit and credit card payments.
- Local bank transfer payments.

Live transactions require valid payment credentials, secure backend configuration, payment verification, webhook handling and successful end-to-end testing.

## 🔒 Security & Reliability

Security considerations for the project include:

- Keeping payment secret keys on the backend.
- Server-side payment verification.
- Secure handling of customer checkout information.
- Payment webhook verification.
- Environment-based configuration.

Additional production security testing and persistent database integration are required before handling real customer transactions.
